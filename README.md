# Cartes NNN 2026 — version légère (téléphone)

Le même jeu que [TCG-NNN](https://github.com/Rigodrolax/TCG-NNN), sans les musiques (14 Mo au lieu de 31 Mo), pour les téléphones où Tampermonkey refuse le gros fichier. Les petits bruitages, les cartes, les duels et le mode en ligne sont identiques : on joue avec les joueurs PC.

**Installer (Firefox Android + Tampermonkey) :** Tampermonkey → Utilitaires → « Installer depuis une URL », puis coller :

https://raw.githubusercontent.com/Rigodrolax/TCG-Light/main/nnn-cartes-balade92-light.user.js
